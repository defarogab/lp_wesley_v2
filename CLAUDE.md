# Instruções do Projeto — Landing Page Wesley Teixeira

## 🚫 REGRAS IMPORTANTES

### Partido político
**NÃO mencionar o partido (PSB ou qualquer outro) em nenhum lugar do site**
sem autorização explícita do usuário em cada caso. Isso inclui:
- Badges, selos ou tags
- Textos do hero, formulário, footer
- Metadados, alt texts, comentários visíveis
- Qualquer elemento renderizado para o público

Se quiser sugerir incluir o partido, **perguntar antes** e aguardar autorização
explícita.
